# California Latino neuroscience research report

Prepared 13 October 2026. This folder contains the 20-page report, an editable Word version, a separate researcher directory, an Excel workbook, references, and a ZIP containing the complete package.

- [20-page report PDF](California_Latino_Neuroscience_Report_20_Pages.pdf)
- [Excel workbook](California_Researcher_Directory.xlsx)
- [Complete ZIP package](California_Latino_Neuroscience_Research_Package.zip)
- [Researcher directory PDF](California_Researcher_Directory.pdf)
- [References and evidence notes](Report_References_and_Evidence_Notes.pdf)
- [Editable Word report](California_Latino_Neuroscience_Report.docx)

The directory contains 19 core neuroscience research leaders, two related-field leaders, and one separately labeled Spain-origin PI. Nineteen unresolved follow-up leads are outside the confirmed active count. Background evidence and lab activity evidence are recorded separately; no identity was inferred from a surname. This is not a statewide census.

The named research plugins were unavailable in the preparation session. Direct institutional pages, primary literature, official datasets, and Europe PMC were used. See the bibliography and source index for evidence and access limitations.
